## 1. 快速开始

### 方式 A：直接打开（推荐）

双击 `index.html`，或把它拖进 Edge / Chrome / Firefox。

本项目使用传统的 `<script>` 标签而不是 ES Module，因此 `file://` 协议下也能正常运行，不需要本地服务器。

### 方式 B：本地静态服务器（可选）

```bash
# 在项目根目录任选一种
npx serve .
# 或
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

> 想把这个原型发给别人玩，可以部署到公网静态托管。将 `index.html`、四份 CSS、`src/`、`assets/` 和 `map_assets/` 按原结构一起上传，或直接上传自包含的 `standalone.html`。详细步骤见 [`DEPLOY.md`](DEPLOY.md)。
>
> 如果对方打开后只有文字没有画面，通常是只上传了 `index.html`，缺少 `styles.css`、`entry.css`、`soul-ui.css`、`diary-ui.css`、`src/` 和素材目录。另外，微信直接发送文件时请先双击 `制作单文件版.bat`，生成可单文件分享的 `standalone.html`；仓库中已附一份当前版本的 `standalone.html`（约 40 MB，已内嵌六名角色、动作图、地图与界面贴图）。

### 调试入口

浏览器控制台中可以访问：

```js
MYGO_UI                 // 当前 UI 控制器
MYGO_UI.game            // 当前对局状态
MYGO_UI.game.units      // 全部单位
MYGO.UI                 // UI 类
```

在 URL 后添加 `?seed=12345` 可以固定随机种子，便于复现命中/暴击结果：

```text
index.html?seed=12345
```

## 2. 操作说明

| 操作 | 说明 |
| --- | --- |
| 标题页 → 开始游戏 | 进入 / 返回当前对局，首次进入为第 1 回合 |
| 标题页 → 存档 / 读档 | 打开存档抽屉，可保存当前进度、读取或删除本地存档 |
| 标题页 → 编队 | 打开羊皮纸编队界面，查看出击成员的全部能力、职业、武器、性别与移动距离 |
| 顶部「标题」 | 战斗中随时返回标题页；当前战场状态会保留 |
| 点击我方单位 | 选中并显示可移动范围（蓝色格子） |
| 点击蓝色格子 | 移动到该格 |
| 点击单位脚下原点 | 原地进入行动菜单 |
| 行动菜单 → 攻击 | 显示红色攻击范围与可攻击目标 |
| 点击攻击范围内的敌人 | 进入侧视战斗演出与结算 |
| 点击「确认结算」 | 关闭结算面板并正式扣血 |
| 行动菜单 → 待机 | 结束该单位行动 |
| 行动菜单 → 撤回移动 | 回到移动前的位置并重新选择落点 |
| 点击「结束回合」/ 按 `E` | 进入敌方回合 |
| `Esc` / 鼠标右键 | 取消 / 返回上一层 |
| `Enter` | 确认当前弹窗 |
| 顶部「存档 / 读档」 | 写入或恢复 `localStorage` 存档 |
| 顶部「说明」 | 查看规则速查 |
| 顶部「重开」 | 确认后重新开始本关 |
| 地图右上 `+` / `−` | 把视口放大到 220% / 缩回适合宽度 |
| `Ctrl` / `⌘` + 滚轮 | 放大 / 缩小地图（保留当前视口中心） |

> 战斗规则：伤害与命中在弹出结算面板时就已锁定；但**只有点击「确认结算」后才会扣除 HP**，符合“先播报、再结算”的简化战斗流程。

### 敌人 AI

每个敌人按以下顺序决策：

1. 优先攻击**曼哈顿距离最近**的我方单位。
2. 距离相同时，优先攻击**当前 HP 最低**的我方单位。
3. 若当前站位不能攻击，则在移动范围内寻找能攻击目标的格子。
4. 若本回合无法攻击，则朝最近目标移动，并优先选择守备/闪避更高的地形。
5. 无路可走时原地待机。

## 4. 战斗公式

所有公式集中在 `src/combat.js`，数值集中在 `src/config.js`。

### 命中率

```text
命中 = 攻击方命中 + 武器命中 + 三角修正
     − (floor(防守方速度 × 1.5) + 地形闪避)
```

- 三角克制：`+15`
- 三角被克制：`-15`
- 最终限制在 `5% ~ 100%`

### 攻击与伤害

武器在数据层用 `damageType: 'physical' | 'magic'` 明确伤害类型，**同一套公式**：

```text
攻击力 = 力量或魔力
       + round(武器威力 × 三角倍率 × 有效倍率)
       + 攻击修正（角色 atkMod + 武器 atkMod）

物理伤害 = 攻击力 − (目标守备 + 地形守备)
魔法伤害 = 攻击力 − 目标魔防
```

- 物魔类型只由**武器**决定，不由角色职业决定。
- 三角克制倍率：`1.2`；被克制：`0.8`；中立：`1.0`。
- 有效修正：`1.5`。武器可声明 `effectiveAgainst: ['armor']`，目标拥有对应 `tags` 时生效。
- 山地 `+3 守备`只进入物理减伤；魔法伤害不读取地形守备。
- 最低伤害为 `1`；暴击时伤害 ×2。

> 例子：高松灯（力量 10）持威力 5 的剑攻击斧兵，触发克制：  
> `攻击 = 10 + round(5 × 1.2) = 16`，再减去斧兵守备。  
> 长崎爽世（魔力 12）持威力 6 的法书：`攻击 = 12 + 6 = 18`，再减去目标魔防。  
> 面板中的「魔力」是独立属性，不再把「攻击」和「力量」混为一谈。

### 暴击

```text
基础暴击率 = floor((技巧 + 幸运) / 2) + 武器暴击
必杀回避 = 幸运
实战暴击率 = clamp(攻击方基础暴击率 - 目标必杀回避, 0, 100)
```

命中后才会判定暴击。本次对齐《风花雪月》的技巧、幸运与暴击率部分；其余战斗公式仍沿用原型，包括暴击伤害 ×2、原有命中/回避和武器三角。参考 [Triangle Attack 的《风花雪月》公式](https://www.fe3h.com/calculations)。

属性总和为 `HP上限 + 力量 + 魔力 + 技巧 + 速度 + 幸运 + 守备 + 魔防 + 移动`，排除等级、派生概率及武器/地形加成。受伤不会降低属性总和。

### 三角克制

```text
剑 → 斧 → 枪 → 剑
```

弓、法书不参与三角克制，对任何武器都是中立关系。

## 6. 如何替换美术素材

地形仍由 `src/assets.js` 程序化绘制；五名我方角色使用 `assets/characters/sprites/` 下的本地素材，由 `src/characters.js` 统一加载和绘制。高松灯、千早爱音的完整去背立绘优先来自 `character assets/processed/`，其余角色由生成器从原始拼图提取。地图小人约 50 × 60，侧视战斗立绘高约 90–105px；头像使用独立的大立绘裁切。原始素材在 `character assets/`，可运行 `python tools/prepare-character-assets.py` 重新生成规整图集。自定义角色仍可通过 `MyGO.Assets.registerPack` 覆盖。

### 6.1 用一个函数绘制

```js
// 在你自己的 js 文件里，确保在 assets.js 之后、ui.js 之前加载
const heroImg = new Image();
heroImg.src = 'assets/tomori.png';       // 路径由使用者自行决定

MyGO.Assets.registerPack({
  units: {
    // 参数：ctx, x, y, size, unit, opts
    tomori(ctx, x, y, size, unit, opts) {
      if (!heroImg.complete) return;
      ctx.imageSmoothingEnabled = false;
      ctx.drawImage(heroImg, x, y, size, size);
    }
  }
});
```

### 6.2 用 `fromImage` 快速裁切图集

```js
const atlas = new Image();
atlas.src = 'assets/units.png';

MyGO.Assets.registerPack({
  units: {
    tomori: MyGO.Assets.fromImage(atlas, { sx: 0,  sy: 0,  sw: 32, sh: 32 }),
    anon:   MyGO.Assets.fromImage(atlas, { sx: 32, sy: 0,  sw: 32, sh: 32 }),
    rana:   MyGO.Assets.fromImage(atlas, { sx: 64, sy: 0,  sw: 32, sh: 32 })
  }
});
```

### 6.3 当前地图贴图

第一关由 `src/garden-map.js` 加载 Flare 纹理图集，以端正方格地面、纹理墙体立面、角楼、桥栏与直立树木形成 2.5D 战场，角色与场景共享前后遮挡排序。素材来源、许可证与制作方式见 [美术说明](docs/FLARE-MAP-ART.md) 和 [素材署名](assets/terrain/flare/README.md)。

第二关继续由 `src/assets.js` 加载原有四张地图底图，按 32px 地形格裁切：

| 地形 | 文件 | 用法 |
| --- | --- | --- |
| 草地/泥地 | `map_assets/raw2/36_9fddb3ef.png` | 取中央四个 620px 裁片，附加草簇、碎石 |
| 森林 | `map_assets/raw2/20_a6be3edd.png` | 取 8×8 图集中四个树冠格 |
| 山地 | `map_assets/raw2/34_9d672dc7.png` | 灰石贴图 + 冷色岩面 |
| 墙体 | `map_assets/raw2/38_c9eef3de.png` | 砌石贴图 + 横向灰缝、顶部受光、苔藓 |

启动时 `MyGO.Assets.loadTerrain()` 预载这些图；文件缺失或加载失败时自动回退程序化地形，游戏不会卡住。原始导出图没有豆包水印，不需要额外擦除。

### 6.4 替换地形

```js
const forestImg = new Image();
forestImg.src = 'assets/forest.png';

MyGO.Assets.registerPack({
  terrain: {
    // 参数：ctx, x, y, size, info
    forest: MyGO.Assets.fromImage(forestImg, { sx: 0, sy: 0, sw: 32, sh: 32 })
  }
});
```

### 6.4 可覆盖的 ID

- 地形：`plain`、`forest`、`mountain`、`wall`
- 我方：`tomori`、`anon`、`rana`、`soyo`、`taki`
- 敌方：`shadow_blade_1`、`shadow_lance`、`shadow_bow`、`shadow_axe`、`shadow_blade_2`、`conductor`

未覆盖的 ID 会继续使用内置占位图。完整示例见 [`docs/ASSETS.md`](docs/ASSETS.md)。

> 注意：自定义绘制函数接收的 `x/y` 是**画布像素坐标**，`size` 是目标格边长（通常为 32）。  
> 请保持 `ctx.imageSmoothingEnabled = false` 以获得清晰的像素边缘。

## 7. 数值与关卡配置

所有可调内容都在 `src/config.js`：

| 配置 | 位置 | 说明 |
| --- | --- | --- |
| 格子尺寸 | `CONFIG.TILE` | 默认 32（逻辑分辨率） |
| 渲染倍率 | `CONFIG.RENDER_SCALE` | 默认 2；只影响背板清晰度，不改素材尺寸 |

| 地形效果 | `CONFIG.TERRAIN` | 移动消耗、闪避、守备 |
| 三角修正 | `CONFIG.TRIANGLE_BONUS` | 威力倍率、有效倍率、命中 |
| 战斗常量 | `CONFIG.COMBAT` | 暴击倍率、命中上下限等 |
| 地图字符 | `CONFIG.MAP_CHARS` | 每行 24 个字符，共 16 行 |
| 武器 | `CONFIG.WEAPONS` | 威力、命中、暴击、射程、`damageType`、`element`、`effectiveAgainst` |
| 单位 | `CONFIG.UNITS` | 属性、性别、位置、阵营、武器、立绘 key |
| 任务文案 | `CONFIG.MISSION` | 关卡标题、目标、副标题 |

地图字符：

```text
. = 草地
f = 森林
m = 山地
# = 墙体
G = 庭院大门（击败钥匙守卫后开启）
```

## 9. 已知边界

这是一个优先跑通战斗循环的原型，因此刻意没有实现：

- 转职动画、学院地图、支援系统、复杂剧情
- 商店交易（`docs/DESIGN.md` 留有扩展位说明）
- 反击、再移动、武器耐久、完整技能系统
- 多关卡流程；当前为单关，胜利/失败后可重开
- 属性膨胀/升级成长、转职与职业精通；当前数值为单关原型配置

另外：

- 存档只允许在我方阶段、无动画/弹窗时写入。
- 读档后若存档处于敌方阶段，会安全回到我方阶段。
- 浏览器禁用 `localStorage` 时，存读档仅在当前标签页内有效。
- 自定义素材需要自行处理加载完成顺序；图片未加载完时可先画占位图。
