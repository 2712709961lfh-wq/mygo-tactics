# 第七话 · 繁星之下的求援

入口：标题页「第七重 · 繁星之下的求援」，或第六章通关后「进入第七章」。`index.html?stage=7` 可直接选择本章。普通版与 `standalone.html` 同步。

## 场景与布阵

30×28 的地下 Live House，以《孤独摇滚》STARRY 的地下演出空间及下北泽 SHELTER 的场馆用途为参考，采用原创地图布局。上方中央为舞台，背墙有 STARRY 字样、幕布、灯架与彩色灯束；鼓组、双侧音箱、电吉他、麦克风、返听音箱构成演出区域。观众区两侧设置吧台、海报、立柱、设备箱和后场调音台，南端为入口。不是动画背景截图或逐格复制。

舞台前沿与两条侧通道都可推进。鼓组、主音箱、设备箱、吧台、调音区、立柱的占地与阻挡格相匹配；固定阻挡不允许穿越。两侧各有一个急救补给点，沿用休憩恢复规则。地形面板使用演出厅地板、舞台地板、隔墙与设备、急救补给点等场景名称。战斗特写同样使用场馆幕布、砖墙、灯光与乐器背景。

18 名「失真回声」由剑、枪、斧、弓、魔法敌人组成，分布在大厅、西侧、东侧和舞台警戒组。接近或交战会激活对应警戒组。没有单独的 Boss，也没有通过某一个关键敌人提前过关的条件。敌军沿用第四章起的平均队伍等级缩放规则，玩家升级后敌方阶段间会继续调整。

## 开场与虹夏入队

约 16.7 秒的开场在真实地图和真实角色素材上播放，镜头先看入口，再揭示整间场馆，最后回到求助与回应。

1. 虹夏独自从南端走入；主角团与敌人在这个镜头中尚未显示。
2. 黑影突然显现，场馆出现大量敌人，短暂的紫色闪光强调异变。
3. 主角团从门口赶来。
4. 虹夏请求帮助，灯回应「我们听见了。一起……把这里守住吧。」
5. 回应时调用一次入队逻辑；虹夏立即成为我方单位，可以在本回合行动。
6. 显示入队信息和「击败全部敌人」目标，交还操作。

Enter 或点击可跳过。跳过会完成入队，不会漏掉虹夏；重复调用不会刷新她已消耗的行动。已入队存档不会再次播放开场，尚未完成开场的存档会重新播放。重新挑战本章会重播求援剧情。演出期间棋盘操作和自动结束回合受到保护。

## 通关与存档

v5.6.7 的「一同寻找归途」使用与开场一致的全屏版式，但从胜利时的战后现场继续。全歼后先由虹夏道谢，爱音询问她为何来到这里；虹夏解释原本与乐队成员约好在 Live House 彩排，推门却见到满屋怪物。爽世邀请她同行，一起寻找回到现实世界的方法，虹夏开心答应。画面使用真实地图 Renderer，保留所有角色战斗结束时的实际位置、朝向、动作与生命状态，不重排、不移回正门、不播放再次入场。镜头先交代舞台与战后现场，再按三位说话者实际站位平滑取景；分散或留在后方的同伴继续停在原地。底部显示头像与字幕，虹夏最后的回应配轻跳音符。六段台词约 24 秒自动播放，也可点击画面／「下一句」／Enter 继续，Esc 或「跳过剧情」跳过；结束后淡出并显示通关结算。

`livehouseEndingShown` 随第七章通关存档保存，完成或跳过后均不重复播放。旧版存档缺少此字段时默认未播放；重新挑战会重置。切换对局或读档时取消旧对话，避免旧剧情结束后覆盖新对局。

任务栏实时显示剩余敌人数及虹夏入队状态。18 名敌人必须全部击败，才会结算全歼胜利和 2000 G 章节奖励。存档保留虹夏入队、存活、等级、经验、属性增长、职业、法术次数、背包、敌人状态和敌军缩放等级；读档校验地图版本、单位集合和入队标志的一致性。

左侧队伍列表支持纵向滚动，快捷键为 1–8，按实际编号选择。地图支持原有缩放、网格、拖动和单位选择。
