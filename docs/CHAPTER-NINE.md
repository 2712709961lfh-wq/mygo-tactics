# 第九关 · 门后的排练回声

版本：5.13.2，2026-11-16。原第九、十关合并为一个章节，在同一张28×34排练室地图内分前、后两段推进。普通版与离线单文件版同步，全局 `SAVE_VERSION` 不变。

## 整关流程

1. 众人从Live House休息室入口进入，仁菜认出自己乐队的排练室，空间异常扩张，幻兵与裂空天马出现。
2. 玩家沿中央地毯向北推进，击败裂空天马，取得奇怪的门的钥匙和钢枪。
3. 队员到北端门旁使用钥匙。开门只推进剧情，不显示胜利结算、不发章节金币；门光效后自动接后半段演出。
4. 门后依然是同一间排练室，中央昴正在与仁菜幻影交战。保留原对话、地图战斗动作及敌军召唤演出，演出可跳过。
5. 对话结束后安和昴加入，玩家击败后半段15名敌军（含仁菜幻影）才完成第九关。击败仁菜幻影后仍需清理其他敌人。
6. 整关只发一次2000G通关奖励。前半段保留原守门目标，开门不要求击败所有普通敌人；离开前未击败的敌人不算击破，也不会在后半段继续行动。

标题页只保留「第九重 · 门后的排练回声」入口，原 `?stage=10` 地址转向第九关起点。两段均显示 `MISSION 09 / CHAPTER 09`；后半段演出注明「后半段」。第八关胜利正常进入第九关，最终结算不再显示进入旧第十关按钮。

## 同一关内的继承

穿门时保留同一个游戏与地图对象，保留队员对象和所有实际战斗数据：当前HP、死亡、异常状态、等级、经验、随机成长、职业、装备、武器耐久、魔法剩余次数、金币、运输队、战利品暂存、回合数、随机数状态和商店本章限购。

队员按后半段剧情队形重新站位；存活队员可重新行动，倒下的队员仍倒下。没有跨章满血、恢复魔法或刷新商店。仁菜此前永久失去时继续保留该结果，采用替代对白；仁菜幻影仍出现。昴在后半段对话结束后加入，支持原有成长、魔法、治疗、转职与存读档。

重开任意半段均从第九关前半段起点开始。结算回合数沿用整关累计；击破数累计前半段实际击破与后半段击破，总敌人数为27。

## 存档兼容

新存档统一写 `stage:9`，用 `rehearsalChapterVersion:1` 与 `rehearsalPart:1/2` 区分前后半段，并记录前半段实际击破数。标题存档槽显示前／后半段和正确队伍人数。

运行时保留旧内部战斗标识9／10与原模板，兼容现有单位ID、动作和旧档；对玩家显示的章节与经济结算始终是第九关。

- 旧第九关未开门档：继续原战斗。
- 旧第九关已开门通关档：载入后直接接后半段演出，保留原战利品与已获得金币；最终不重复支付旧第九关奖励。
- 旧第十关未通关／已通关档：继续后半段对应状态，保留昴入队、成长、伤势与敌人死亡；后续保存统一写为第九关后半段。
- 旧章已获得的金币不回扣。旧奖励标记9／10统一归为9，避免重复结算；原商店购买记录保留。
- 开门瞬间保存的档载入后推进至后半段，防止停在无法继续的门口。重复读取不重复生成昴或发奖励。
- 属性修订仍兼容v5.12.1／v5.12.2之前的存档，按旧生命比例迁移伤势。
- v5.13.1 后半段普通敌人属性修订通过 `rehearsalFinaleBalanceVersion:1` 标记，兼容v5.12.1～v5.13.0保存的旧属性伤势；更早存档直接按最早的HP上限迁移，避免重复换算。昴和Boss不受本次修订影响。
