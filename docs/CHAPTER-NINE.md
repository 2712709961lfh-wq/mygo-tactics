# 第九关 · 门后的排练回声

版本：5.12.2。新增章节不更改 SAVE_VERSION；第 1–8 关继续沿用现有规则。

## 场景与开场

以《Girls Band Cry》刺团排练室为视觉参考，使用暖色吸音墙、镜面、暗红地毯、鼓组、键盘、音箱、麦克风、乐器架、线缆和沙发休息角重新组织为战棋地图。战斗背景使用同一组颜色和设备。战术布局与异常扩张部分为原创，并非动画平面图的逐格测绘。

地图为 28×34，队伍从南侧休息室入口进入；中央地毯引导向北。固定设备是不可通行的障碍，形成可从两侧绕行的局部掩体与通道；飞行单位也不能穿过隔音墙或关闭的门。

开场使用与第七、八关一致的全屏地图演出：顶部章节标题、中间真实地图、底部角色头像与字幕。约 20 秒，点击、Enter、空格、Esc 可跳过，并一次性完成所有开场状态。

1. 虹夏建议众人先到 Live House 的休息室休息。
2. 入口门扇打开，队伍从入口进入；仁菜惊讶地认出自己乐队的排练室。
3. 镜面与吸音墙之间的空间延伸，房间中段从折叠状态展开为 14 排额外空间。
4. 普通幻兵、重装、天马和裂空天马依次在召唤光阵中现身。
5. 镜头转向最北端，奇怪的门在苍蓝光芒中浮现。
6. 众人决定击败守门敌人、取得钥匙、打开出口，交还玩家操作。

标题页直接体验第九关时，仁菜和虹夏在队；从第八关正常进入时继承真实招募、成长、天赋、金币和装备状态。此前明确失去仁菜的进度保持失去状态，采用同伴认出她曾描述的排练室的替代对白，避免复活已经失去的成员。

## 敌军与 Boss

总计 12 名敌人：7 名普通幻兵、2 名重装、2 名普通天马、1 名天马 Boss。分前、中、后与守门警戒组，接近或攻击才会惊动相应队伍。敌人采用第九关固定属性，遵循 v5.8.10 后的全战役固定数值规则。

| 裂空天马·门之守卫 | 数值 |
| --- | --- |
| 等级 | 15 |
| HP | 40 |
| 力量 / 魔力 | 17 / 8 |
| 技巧 / 速度 / 幸运 | 16 / 16 / 9 |
| 守备 / 魔防 | 11 / 18 |
| 移动 | 6 |
| 武器 | 钢枪 |
| 战利品 | 奇怪的门的钥匙 ×1、钢枪 ×1 |

v5.12.2 按用户指定数值更新Boss，总属性141，等级保持15。旧档生命按原46HP上限的剩余比例换算，保留死亡与战斗进度；本次修订有独立标记，重复读取不重复换算。

Boss 以苍蓝双环、发光羽片、光晕和攻击枪光区别于普通天马；这些效果跟随地图移动与侧视战斗。保留天马飞行属性和弓的飞行特效弱点，无锁血。普通重装守备 20、魔防 5，适合用魔法突破。

v5.12.1 参考玩家存档的等级／总属性（虹夏11／109、仁菜14／119、雪月13／115、立希9／92）校准普通敌军。总属性按HP上限、力量、魔力、技巧、速度、幸运、守备、魔防、移动九项相加。普通剑／斧／弓／枪／咒幻兵保持12级，总属性108～111；重装、天马保持13级，总属性分别114、115。保留物理单位魔力、法师力量等非主攻属性，避免全部集中于有效能力。

旧存档读取时采用新基础属性，生命按旧生命上限的剩余比例换算，保留位置、死亡、警戒、行动、开场与开门进度。新增局部属性修订标记保证只迁移一次，不变更全局 SAVE_VERSION。

## 开门与胜利

- 击败 Boss 后立即发放两件战利品，但继续留在地图上。
- 只有开场完成、Boss 已死亡、队员存活且尚未行动、处于我方阶段、与门相邻一格时才能使用钥匙。
- 使用门钥匙消耗钥匙并结束行动，播放开门光效，然后显示胜利结算。其他敌人可以尚未击败。
- 运输队在本游戏中随时可访问；门钥匙在运输队或战利品暂存中时，门旁队员也可直接使用，防止背包及运输队都满导致卡关。其他队员背包中的钥匙仍需正常转交。
- 携带门钥匙的队员战死时，钥匙自动回收至运输队（满仓时进入暂存），幸存队员仍可开门。
- 通关奖励 2000 G，与其他章节一致，只发放一次。
- 地形与单位面板显示门及钥匙说明；地图为携钥匙角色显示钥匙图标。
