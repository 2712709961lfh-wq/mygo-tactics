# 迷途回声：心境横屏界面 v3.1

本次依据的故事是：五名少女经历朋友的背叛与抛弃，进入心声被封闭的内心世界；她们在与怪物、回忆的对抗中重新建立联系，最终面对自己的心魔。本次将这一背景落实到界面与角色档案文案，现有两关的规则和通关目标继续使用真实对局状态。

## 视觉方向

v3.1 根据贴图重制要求，将主题落实为“深蓝皮革装订的内心手记”。背景使用皮纹；情报、档案、存档、说明与章节卡使用真实旧纸照片；外框保留缝线与卷边。标题中央为项目已有五名角色图片组成的纸上合照，配合“这一次，不再独自迷路”的题字。旧版 v3.0 的多边形心门已替换。

新增素材取自 yd 的 GUI elements 和 Andrea Stöckel 的 Parchment Paper Background Texture，两处来源均明确标注 CC0。下载的原文件、授权全文、加工步骤与 8 张运行贴图的对应关系见 [UI 素材来源](../assets/ui/SOURCES.md)。运行时不依赖网络字体或远程图片。人物图继续使用项目原有素材，不属于新增 CC0 授权范围。

边框通过 `border-image` 九宫格切片适配不同大小的窗口；文字区域保持透明，露出底层纸张纹理。深色按钮使用皮纹与金色文字，纸面正文改为褐墨色，选中与禁用状态继续体现真实交互。

标题改为“迷途回声 / ECHOES OF THE LOST”，保留 MYGO!!!!! 识别。菜单使用“走入心境”“记忆留痕”“同行之人”，并保留第二关入口。角色档案增加本次背景下的“未说出口的话”；这些文字是此版本的创作，并非对原作人物事件的考据。

## 布局与参考

在线参考：[Game UI Database — Fire Emblem: Three Houses](https://www.gameuidatabase.com/gameData.php?id=419)。重点观察 Action Menu、Player Vitals、Enemy Health、Stats 等界面的信息组织。参考截图：[战斗 HUD](https://www.gameuidatabase.com/uploads/Fire-Emblem-Three-Houses12242020-030040-6969.jpg)、[行动界面](https://www.gameuidatabase.com/uploads/Fire-Emblem-Three-Houses12242020-030037-40565.jpg)。借鉴的是稳定的操作区域、双方状态对照，以及 HIT / DMG / CRT 三项预测的并列关系；项目未引入火焰纹章的图片、字体或 UI 贴图。

主界面为 1360×768 的统一横屏逻辑画布，接近 16:9。保留俯视网格战棋玩法。左侧固定五名同行者头像、生命条、行动状态和数字键；中间优先显示完整的 24×16 战场；右侧为地形、单位、任务信息和行动按钮。顶部显示章节与阶段，底部放置操作提示、网格和全屏按钮。长档案与说明只在各自面板内滚动。

地图本身保留 3:2 的格子比例，避免棋盘和单位被拉伸；独立战斗演出改为 576×324 的 16:9 画布，并重新放置双方站位与石台。

窗口改变时整体等比适配。竖屏窗口将游戏顺时针旋转 90°；点击换算同时逆转坐标，缩放和滚动继续使用地图的逻辑坐标。界面不会在窄窗口中变成上下堆叠的网页。

## 操作

- 点击地图上的同伴，或按 1–5 / 点击左侧头像选择同伴。未移动时可以切换同伴；移动后需完成或撤回当前行动。
- 再次点击当前移动阶段的同伴头像，可以进入原地行动菜单。
- 右侧显示真实 HP、能力、武器、地形，以及当前可用操作。
- 攻击阶段指向目标时显示命中、伤害和暴击预测，发动攻击前仍有确认界面。
- Esc / 右键返回；E 结束回合；G 切换网格；F 切换全屏；Enter 确认结算。
- 地图支持 100%–220% 缩放。任务步骤依据钥匙与门的真实状态更新，没有添加虚构的心声数值或养成机制。

## 文件与离线运行

`index.html` 为主入口；`soul-ui.css` 为横屏布局，`diary-ui.css` 为 v3.1 贴图皮肤；`src/viewport.js` 为窗口适配与点击换算。`src/ui.js` 接入队伍栏与快捷操作，`src/entry.js` 同步档案及存档章节信息，`src/battle.js` 使用横屏演出画布。`build-standalone.js` 会将四份样式、CSS 引用贴图及脚本全部内嵌，生成自包含的 `standalone.html`。

修改前备份为 `backups/before-landscape-ui.zip`，战斗脚本原版另存于 `backups/before-landscape-battle.zip`。地图重制前的备份与 CC0 素材授权继续保留。

v3.1 修改前的界面备份为 `backups/before-textured-ui.zip`；加工脚本为 `tools/prepare-ui-assets.py`，素材联系表为 `docs/previews/ui-materials.jpg`。
