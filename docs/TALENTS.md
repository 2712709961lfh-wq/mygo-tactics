# 个人天赋

v5.14.0，2026-11-16。指定角色分别在15、20、25级自动觉醒个人天赋1、2、3，无须装备或消耗物品；三档累积生效，转职不移除个人天赋。

## 个人天赋1 · 15级

| 角色 | 名称 | 实际效果 |
| --- | --- | --- |
| 雪月 | 剑意 | 装备剑时力量＋3，参与物理伤害及力量抵消负重的攻速计算；主动、追击和反击均适用。换用其他武器或未装备时立即失效，不写入永久力量。 |

| 要乐奈 | 幸运猫 | 对物理和魔法攻击的回避值＋5，即命中计算减少5个百分点，仍遵守原有命中率上下限。 |

爱音结束非攻击行动后，有合法对象时会弹出换位选择，可选队友或「不交换」。也可在本回合点选已行动的爱音再次打开选择。尚有合法换位选择时不会自动结束回合；手动结束回合可放弃换位。换位机会及攻击标记随存档保存，下回合清空。

冰霜剑气在整次交战结束后施加，本次交战的反击与追击沿用原判定。玩家阶段施加后，目标接下来两个敌方阶段均受减速；敌方阶段反击施加时，当前未完成的阶段不消耗持续时间，从后续完整敌方阶段开始计数。与原有速度−5同时存在时取较强减速，不相加。剩余回合和反击施加标记随存档保留，重复读取不重置；跨章清除临时状态。

## 升级、存档与结算

- 14→15级的升级报告显示觉醒名称与效果；属性增量同时呈现随机成长与天赋增加后的实际变化。
- 所有固定属性奖励不写入随机成长记录。读档按模板＋既有随机成长＋等级天赋重建，因此旧档达到15／20／25级自动生效，重复读取、转职及跨章不重复增加。
- 雪月、爱音和立希的条件加成在战斗预告、实际伤害／命中／暴击、派生属性中即时计算，移动或换装不永久写入属性。
- 锁定战斗在所有虚拟单位上预演仁菜与昴的回复，确认前不改变真实队友HP。爱笑女孩的随机结果在锁定时确定，确认不重抽；战报及地图显示保留次数、天使扣血和实际回复量。
- 昴仅剩一次攻击魔法时，若首击保留次数，仍可正常追击；未保留则取消后续施法。预告标明依赖保留次数的攻击，预告本身不抽取随机数。次数为零时不能施法。
- 治疗魔法先恢复目标与虹夏本人，再结算经验；本次施法升至15级时从下一次施法起生效。仁菜本次击破才升至15级也从后续击破起触发。
- 昴的天赋同样从觉醒后的下一次使用／击破起生效。旧档按等级自动生效，无须重新升级或重开游戏；随机数状态沿用现有存档保存方式。
- 所有回复保留生命上限，不能复活倒下单位。游戏发布版本递增，`SAVE_VERSION`保持原值。
