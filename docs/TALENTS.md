# 通用与个人天赋

v5.27.0，2026-11-24。所有可培养角色在10级习得通用天赋，并分别在15、20、25级自动觉醒个人天赋1、2、3，无须装备或消耗物品；各档累积生效，转职不移除天赋。

## 通用天赋 · 10级

所有九名可培养角色（高松灯、千早爱音、要乐奈、长崎爽世、椎名立希、雪月、井芹仁菜、伊地知虹夏、安和昴）均习得「掌握战斗」：**命中＋5、技巧＋1**。

- 技巧＋1计入基础属性，参与原有命中、暴击和属性总和计算。命中＋5在技巧、武器及装备命中修正之外独立相加，适用于物理／魔法、主动攻击／反击／追击，仍遵守最终命中率上下限。固定效果不会修改个人成长率。
- 9→10级的升级报告显示名称、效果及含技巧奖励的实际属性变化。角色资料中以「通用天赋 · Lv.10」展示，原有个人天赋编号保留。
- 起始已达10级和旧存档已达10级均自动获得；技巧奖励独立于随机成长记录，重复读取、转职和跨章不会累加。低于10级不会提前生效，敌方及幻影沿用原有天赋阵营限制。

## 升级、存档与结算

- 14→15级的升级报告显示觉醒名称与效果；属性增量同时呈现随机成长与天赋增加后的实际变化。
- 所有固定属性奖励不写入随机成长记录。读档按模板＋既有随机成长＋等级天赋重建，因此旧档达到10／15／20／25级自动生效，重复读取、转职及跨章不重复增加。
- 雪月、爱音和立希的条件加成在战斗预告、实际伤害／命中／暴击、派生属性中即时计算，移动或换装不永久写入属性。
- 锁定战斗在所有虚拟单位上预演仁菜与昴的回复，确认前不改变真实队友HP。爱笑女孩的随机结果在锁定时确定，确认不重抽；战报及地图显示保留次数、天使实际回复量。
- 昴仅剩一次攻击魔法时，若首击保留次数，仍可正常追击；未保留则取消后续施法。预告标明依赖保留次数的攻击，预告本身不抽取随机数。次数为零时不能施法。
- 治疗魔法先恢复目标与虹夏本人，再结算经验；本次施法升至20级习得同心时，从下一次施法起自疗。仁菜本次击破才升至15级也从后续击破起触发。
- 昴的天赋同样从觉醒后的下一次使用／击破起生效。旧档按等级自动生效，无须重新升级或重开游戏；随机数状态沿用现有存档保存方式。
- 所有回复保留生命上限，不能复活倒下单位。游戏发布版本递增，`SAVE_VERSION`保持原值。
