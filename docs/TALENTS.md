# 个人天赋1

v5.9.0，2026-11-15。指定角色达到15级自动觉醒，无须装备、消耗物品或额外操作；转职不移除个人天赋。

| 角色 | 名称 | 实际效果 |
| --- | --- | --- |
| 高松灯 | 行动者 | 速度＋2，参与攻速、回避和追击判定，直接显示于基础属性。 |
| 要乐奈 | 幸运猫 | 对物理和魔法攻击的回避值＋5，即命中计算减少5个百分点，仍遵守原有命中率上下限。 |
| 长崎爽世 | 魔力觉醒 | 魔力＋2，影响魔法攻击、治疗量等，直接显示于基础属性。 |
| 椎名立希 | 队友守护 | 上下左右曼哈顿距离恰好1格的存活友方守备、魔防＋1。不作用于自己、敌方、斜角或隔一格单位；立希倒下、离场或移开立即失效。 |

| 伊地知虹夏 | 同心 | 施放圣疗、远程治疗、群体治疗等真正恢复HP的治疗魔法时，自己回复与目标实际恢复量相同的HP。群体治疗按各目标实际恢复总量计算一次，受自身生命上限限制。不因用药、吸血攻击、传送、魔防支援或解除异常触发。 |

「同心」的回复量原请求未给出，本版采用目标实际恢复量；不计算溢出治疗，不递归触发。雪月未被指定个人天赋，维持现状；敌方同名幻影不会获得我方天赋。

## 升级、存档与结算

- 14→15级的升级报告显示觉醒名称与效果；属性增量同时呈现随机成长与天赋增加后的实际变化。
- 灯、爽世的固定属性奖励不写入随机成长记录。读档按模板＋既有随机成长＋等级天赋重建，因此旧档达到15级自动生效，重复读取、转职及跨章不重复增加。
- 爱音和立希的条件加成在战斗预告、实际伤害／命中／暴击、派生属性中即时计算，移动不永久写入属性。
- 锁定战斗只在虚拟单位上预演仁菜的回复；确认后真实单位只结算一次。战报和地图显示实际回复量。
- 治疗魔法先恢复目标与虹夏本人，再结算经验；本次施法升至15级时从下一次施法起生效。仁菜本次击破才升至15级也从后续击破起触发。
- 所有回复保留生命上限，不能复活倒下单位。游戏发布版本递增，`SAVE_VERSION`保持原值。
