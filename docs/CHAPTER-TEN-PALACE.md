# 第十关 · 鎏金王座的铁蹄

版本：5.16.0，2026-11-18。本关接在合并后的第九关之后；原昴入队与仁菜幻影剧情仍属于第九关后半段。

## 地图与开场

地图为30×36。金白大理石、金色边饰、深红地毯与帷幔、拱窗、成排立柱、三头宫灯、花台及北端王座构成宫殿。地图与侧视战斗共用金白、酒红配色。

v5.16.0 使用LPC室内石砖、红毯与雕像素材增强地面和家具细节：象牙白石砖、双色回廊、环形拼花、金线地毯、石质半身像、长壁旗、王座纹章及双层圣泉。柱体增加金色箍环，墙边增加地面阴影。雕像沿用北侧花台的原有阻挡范围；不改变可通行地形、敌军站位或属性。柱子、雕像、王座与花台挡住身后单位时自动半透明，血条始终可见，旧档仍可继续。

队伍在南端宫门内集合，中央红毯通往北端王座厅。立柱分隔中央大道与两侧回廊，柱间允许横向换线；立柱和花台具有对应阻挡格，飞行单位也不能穿越。左右圣泉位于零起算坐标(5,17)、(24,17)，沿用据点的守备＋2、回避＋10、我方阶段开始回复最大生命20%（向上取整）。

约13秒的真实地图演出：众人入宫，镜头经过回廊守军，转向王座与金鬃卫长，最后展示全图及目标。点击、Enter、空格、Esc可跳过。完整播放与跳过均还原临时坐标，完成状态会保存。
