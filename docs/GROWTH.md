## 升级判定

每项实际成长率 `r = max(0, 个人成长率 + 当前职业成长修正)`。每级该属性保证提升 `floor(r / 100)`，再以 `r % 100` 的百分比概率额外提升 1。例如 60% 是 60% 概率 +1，150% 是保证 +1 且 50% 概率再 +1。

九名同伴均按原作学生的保底规则处理，每级至少两项属性上升。本作实现为：若整组随机结果不足两项，重新判定整组；没有逐条复刻原作内部随机数调用顺序。成长使用各角色独立且随存档保存的随机状态，不受战斗命中、暴击随机数消耗影响。

HP 上限提升时当前 HP 同量增加，保留缺血量。倒地角色不会因成长复活。移动不成长；文档未提供魅力成长、个人能力上限，因此本次没有添加魅力或自行编造个人能力上限。等级最高 99，满级后经验归零且停止获取。

## 经验与升级门槛

经验按原作内部数值记录，升级需要的经验随等级增加，界面显示当前经验／本级需求。例如 Lv.5 需要 146，Lv.6 需要 161，Lv.10 需要 235，Lv.20 需要 611，Lv.22 需要 716，Lv.50 需要 2809。Lv.1–50 采用参考资料中的逐级表，包含 Lv.21–23 的曲线拐点；Lv.51–98 延续 `floor(716.8 × 1.05^(等级−22))`。后半段是曲线延伸，尚无逐级原作数据核验。

一次行动的经验奖励最多等于当前等级的完整升级需求。经验跨级后保留溢出数值，例如爽世从 `145 / 146` 获得 14 后升级，变为 Lv.6 的 `13 / 161`。

### 战斗经验（困难）

设 `d = 敌方等级 − 我方等级`，限制在 −20 至 +20。困难难度等级差系数如下：

| d | 系数 |
| --- | ---: |
| −20 | 0 |
| −19 至 −7 | 0.05 |
| −6、−5、−4、−3、−2、−1 | 0.10、0.20、0.30、0.40、0.50、0.60 |
| 0、1、2、3、4 | 0.70、0.80、0.85、0.90、0.95 |
| 5 至 7 | 1.00 |
| 8 至 9 | 1.05 |
| 10 至 15 | 1.10 |
| 16、17、18、19、20 | 1.15、1.20、1.30、1.40、1.50 |

击破奖励原值为 `敌兵种经验基数 × (敌等级+9) / 10 × 等级差系数 × 首领／魔物系数`。首领或魔物的系数为 2，普通单位为 1，同时满足两者不重复翻倍。

未击破时为 `击破奖励原值 × 本场实际扣除的HP / 敌方最大HP / 2`。最后一步向上取整；未命中、零伤害没有经验。一次完整交战合计首击、反击与追击造成的伤害，只结算一次；我方在敌方阶段反击同样能获得经验。本场死亡的角色不获得经验，击败最后一名敌人仍先结算成长再进入通关流程。预览、取消、待机、开门和地图机关不提供经验。

原创影兵、梦境敌人没有原作对应的兵种经验数据，本作映射为基础 30，第二关指挥者为 40；带 `monster` 标签的敌人应用魔物系数。以上基数是本项目适配值，不是原创敌人具有原作数据的声明。等级差、伤害占比、首领／魔物修正沿用参考公式。

### 辅助魔法经验

`ceil((施法者等级 + 9) × 魔法系数 × 回合系数)`，按一次有效施法结算。与目标等级、回复量和范围内人数无关。满血目标等无效施法不结算、不消耗魔法。

| 魔法 | 系数 |
| --- | ---: |
| 圣疗 Heal | 1 |
| Recover、Physic、Restore、Ward | 1.5 |
| Silence、Rescue | 2 |
| Fortify、Warp | 3 |

回合系数：1–20 回合为 1；21–25 为 0.95；26–30 为 0.90；31–35 为 0.85；36–40 为 0.80；41–45 为 0.70；46–50 为 0.60；51–55 为 0.50；56–60 为 0.40；61 回合以后为 0.30。

当前爽世仍只学会火焰与圣疗。其余魔法的经验系数供已实现魔法系统使用，本次不会自动让角色学会高级魔法。原作雕像、个人特技、经验宝珠等奖励未接入；当前可用装备和能力中没有这些经验加成。教学、舞蹈、骑士团计策等本项目尚无对应行动，未扩展相关经验获取。

## 查看与保存

「同行之人／编队 → 成长率」可查看八项个人、职业和实际成长率。能力资料页与战场情报显示经验，升级后弹窗列出八项属性前后数值与增量，确认后继续行动或通关演出。

每名角色保存 `growth.version / level / exp / gains / rngState`。读档从模板基础能力加累计成长重建，先恢复 HP 上限再恢复当前 HP。跨章保留等级、经验、成长和随机状态，按现有关卡规则补满 HP 与魔法。旧存档缺少成长字段时保留地图、背包及行动进度，从原模板等级、零经验开始，不额外补发历史经验。损坏或越界的成长字段会拒绝读取。
