# 第二关：星铃花镇 · 沉睡的花语（v4.5）

2026-11-11。40×28 格，24 名敌人，六组分区警戒。保留童话梦境的高清纹理与粉紫、银蓝花树，将上一版河道、三条渡河路线、钥匙与封闭宫苑彻底替换为错落村舍、中央集市及五处访问目标。

## 新参考与两章区别

参考：《火焰纹章 if》暗夜第 8 章「氷の村の少女 / Cold Reception」。核对资料：[Fire Emblem Wiki](https://fireemblemwiki.org/wiki/Cold_Reception)。原作以击败 Kilma 为胜利条件，分布五座村庄，访问数量决定金钱奖励；敌方传令枪兵会优先访问村庄并触发增援。

本关借鉴分散访问点、访问顺序与分兵选择，将它们改编为适合本游戏世界观的星铃；并非复制原作地图、奖励或增援规则。本版没有访问时限与村庄抢占 AI，压力来自六组真实区域警戒、访问消耗一次行动及铃声惊动当地守卫。

| 设计 | 第一章：黄昏的迷途庭院 | 第二章：星铃花镇 |
| --- | --- | --- |
| 布局 | 纵向河道、三路渡河、封闭内庭 | 非对称村舍、集市、林地与环形街巷 |
| 推进 | 取钥匙开门后进入内庭 | 五处目标任选三处，访问顺序自由 |

| 战术取舍 | 选择渡口、开启浅滩、夺钥匙 | 分兵或集中、选取目标、通过集市转线或绕行 |
| 美术 | 冷灰旧战场与废墟 | 粉紫银蓝花树、彩色纹理屋顶、暖窗与小池塘 |

## 星铃与战术区域

所有坐标下表采用玩家界面的列字母 / 行号，从 1 开始。规则和渲染共用实际地图数据；房屋占地为不可通行墙格，所有可通行格、五处星铃和首领均连通。

我方未行动单位停在星铃格，行动菜单会出现「唤醒星铃」。消耗一次行动，回复自身最大 HP 的 30%（向上取整，封顶），记录此铃已唤醒，并警觉对应警戒队。每处只能唤醒一次；五处任选三处，配合击败指挥家即可通关，两项可任意顺序完成。仅全灭敌军不能跳过星铃目标。无隐藏倒计时。

六组分别为西侧花屋、南方约定屋、中央集市、北方回忆屋、东侧心愿屋与晨光露台，每组 4 人。警戒按真实可通行地形距离判断。三处休憩据点在逻辑坐标 (5,16)、(18,14)、(28,20)，沿用我方阶段开始回复 20% HP。直开第二章为五人；通关第一章已招募雪月则六人。

## 修复投影与 2.5D

- 移除地面的横向斜切、旋转和纵向压缩，仿射矩阵 a=d=1、b=c=0；每格为 32×32，网格横平竖直。
- 画布逻辑尺寸 1328×988，2 倍背板为 2656×1976；地面、范围、路径、点击与镜头聚焦仍使用同一坐标转换。
- 2.5D 来自建筑前墙、侧墙、双坡屋顶、石台、直立树木和脚点深度排序。高度仅作用于装饰物件，不参与地面和点击坐标的扭曲。
- 房舍、屋顶、门与石路使用已有 Flare 原始 512～1024px 栅格纹理，花树、花丛使用已授权 Avalon 素材。屋顶分别调为蓝、紫、玫瑰色，窗光统一暖色；沿用 4096×2048 高清图集。
- 树木及房屋遮住后方角色时淡化，血条与编号星铃提示位于可见前层。角色头部点击范围仍与直立精灵一致。
