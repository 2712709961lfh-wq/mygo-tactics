# 职业经验与专精奖励

v5.18.0，2026-11-18。当前载入的44种职业全部具有独立职业经验和专精奖励，适用于九名可培养角色。普通版与离线单文件版共用规则。

## 职业经验

|职业组|满条经验|
|---|---:|
|平民、贵族|20|
|初级|60|
|中级（舞者除外）|100|
|高级|150|
|最上级（DLC除外）|200|
|舞者、五种DLC职业|150|

角色等级经验EXP与职业经验CEXP分别记录。参与一场敌我交战，当前职业经验＋1；主动攻击、被攻击、反击、未命中、零伤害都算参与。连续攻击和追击构成的一整场只计一次。本场结束后撤退的同伴也保留这一次职业经验；阵亡规则下不发角色等级经验。

成功施放一次辅助魔法或执行一次辅助战技也加1职业经验，范围魔法不按目标数量重复计数。仅预览、取消、失败、待机、用药和机关不增加。到99级仍可获得职业经验；已满条的职业停止积累，不溢出至其他职业。

每个角色分别保存各职业的经验，转职不清空。满条自动习得该职业奖励：可装备技能自动填入空栏，最多装备5个；超出后可在「标题 → 同行之人 → 职业专精」手动替换。个人天赋与通用天赋使用原来的独立规则，不占这5栏。同名奖励只学一次，例如平民和贵族的HP上限＋5。

技能学会后可跨职业装备。战技不占技能栏，职业限定战技需要切回指定职业才可用。战斗行动中的「职业战技」入口选择攻击战技或辅助目标；换武器、转职和结束行动会取消当前战技。普通攻击仍是默认攻击方式。

## 数值与战斗适配

- 初级属性奖励以及HP上限＋5使用独立增量同步，不写入随机成长记录，反复装备、读档与跨章不会叠加。增加生命上限不额外治疗，不会使撤退角色复活。撤退同伴可管理专精技能，延续此前撤退角色可以转职的规则。
- 发起交战条件、HP低于50%／25%条件，以及祈祷的HP至少2条件按原文文字处理。原文回击描述使用HP高于50%。条件属性进入战斗预告和实际掷骰；战斗中HP变化可改变后续每击的伤害和概率，追击资格与顺序在交战开始时确定。
- 埋伏提前防守方反击；强攻提前主动方原本可用的追击；回击使满足条件的防守方追击并封锁对方普通追击。需要射程内有可用武器，仍受耐久、不可追击和死亡截断约束。
- 祈祷、大盾、圣盾、灭杀和暗杀只在锁定交战结果时额外消耗随机数，预告不掷骰。已锁定效果只结算一次。灭杀／暗杀无法绕过首领、魔物、关键剧情单位和保护HP。
- 蛇毒整场命中后触发一次，取目标生命上限的20%向下取整，不会致死。防守／魔防封锁在实际造成伤害后施加−6，持续到目标下次所属阶段结束；与同属性其他减益取最大值。哈气与恢复魔法可防止／清除封锁。
- 生命吸收按用户指定文章的伤害表述处理：击破时回复本次实际损失HP的50%，向下取整，不按过量伤害治疗。这里明确采用该文规则。回复在我方阶段开始治疗生命上限的20%，向下取整。
- 特殊舞蹈强化技巧、速度、幸运各4，持续至当前我方阶段结束。舞者可用基础舞蹈令已行动同伴再行动；不能对另一舞者使用，防止舞者相互循环。DLC魔力转换在敌方发起的魔法交战命中后，提供力量、魔力、技巧、速度、幸运、守备、魔防各3，持续至下一次我方阶段结束。
- 空手格斗是学会并装备对应技能后可选择的攻击手段，不占背包，不耗耐久，威力0、命中80、重量0、射程1、主动连续两击。骑乘和飞行职业禁用，其他武器专业不妨碍使用已装备的空手技能。
- 攻击战技按一次行动收取整笔耐久，即使提前击破敌人也收取完整消耗；多段战技的后续攻击不再额外收费。只能使用对应实体武器，不能以空手或法术替代。流星9耐久，暗杀4，猎箭齐发5，猛烈铁拳5，三角攻阵3，战鬼一击5，猛烈气旋3；不会附加普通连续攻击或普通追击。
- 带回、冲撞、拉近、重击和移形换位在行动前验证所有落点、穿越格、占用、可见性及地形通行。偷窃检查相邻、速度严格高于目标与背包空格，只能取非武器物品；同时移除对应掉落，读档不会复制战利品。

## 存档与兼容

`classMastery`含内部数据版本1、各职业经验、已装备技能ID。技能解锁由已取得资格的职业及满条经验推导，不信任外部任意技能标记。拒绝负数、非整数、超上限、未知职业、未取得资格的职业经验、未学会技能及超过5栏等存档。原有全局`SAVE_VERSION`不变。

旧存档缺少职业专精字段时从各职业0经验开始，保留原有等级、成长、职业与剧情进度。跨章继承经验和技能装备，按原有规则恢复HP和魔法次数；战斗临时强化、减益以及本次战技选择不跨章继承。

## 验收

运行`node tests/test-class-mastery.js`覆盖门槛、解锁、技能效果、随机触发、战技、存档、旧档与跨章。所有引擎回归测试均载入职业专精模块。

浏览器可打开`index.html?mastery-demo=unlock`：爽世修道士职业经验59/60，并已有4个专精技能。返回战场对受伤的灯使用圣疗，会满条学会魔力＋2并自动填入第5栏。`index.html?mastery-demo=skills`直接展示满条状态。这些验收入口采用内存存档，不写入正常存档。
