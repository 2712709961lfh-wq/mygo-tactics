# 固定敌军数值

v5.8.10 起，各章以固定敌军配置支持逐章推进的战役难度。第一至三关保留原有固定数值；第四至八关移除按队伍平均等级、最高等级或总属性缩放的运行逻辑。

| 关卡 | 固定敌军等级与配置 |
| --- | --- |
| 第一至三关 | 各自原有模板 |
| 第四关 | 普通敌军 Lv.8，往日之影 Lv.10，原关卡属性模板 |
| 第五关 | 普通敌军 Lv.8，统领 Lv.10；普通重装 24 HP，统领 36 HP |
| 第六关 | 巡守及全部四波援军 Lv.8，面具人 Lv.10；初始单位和援军均使用各自固定模板 |
| 第七关 | 全部 Lv.9，固定模板加此前确认的面板 +17：物理兵有效 +13、法师有效 +12 |
| 第八关 | 普通幻兵、重装、天马 Lv.10，双幻影 Lv.12；保留最新分配：幻兵面板 92～96，重装／天马各 102，双幻影各 120 |

玩家等级、属性、入队／撤退、队伍人数、导入成长、回合数及召唤时机都不会改变这些配置。敌人当前 HP、耐久、法术次数、战斗状态与临时减益仍正常结算。

固定配置通过 `applyFixedEnemyStats` 应用于初始化、召唤和读档，不在每轮根据队伍重算。第六关召唤只初始化新出现单位，不重算地图上已有敌人。

新存档使用 `fixedEnemyStatsVersion:1`。旧存档的缩放等级与强度字段仅用于重建原 HP 上限，再按伤势比例迁移到固定值，保留阵亡、行动、警戒、位置、灯、宝箱、波次、招募与剧情进度。旧缩放公式仅保留在 `restoreLegacyEnemyScale`／`restoreLegacyEighthScale` 中供历史存档转换；正常开局、回合和新存档不调用。

`node tests/test-fixed-enemy-stats.js` 覆盖全八章不同队伍强度／人数、成长导入和回合推进的数值一致性，第六关全部四波援军、第四至八关旧缩放存档的伤势／阵亡／进度迁移及重复读档稳定性，并禁止正常流程调用旧缩放方法。
