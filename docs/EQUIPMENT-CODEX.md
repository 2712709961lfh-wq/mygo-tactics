## 独立图标与统一风格

166 条记录各自使用一张不同的本地透明 PNG，普通版与强化版分别配图。36 种魔法各自使用对应元素的魔力球、晶石、卷轴等示意图，不再共用两张法杖图片。

全部当前图标选自原供应站 Free Game Assets 的 Fantasy RPG Core 同一套 painterly 奇幻素材，保留原有的纸张、皮革、金属边框和透明插画展示方式。素材标注 CC0，可免费使用与修改；三张带背景的弓箭原图按轮廓抠图，其余保留原有透明通道。详见 [素材来源](../assets/equipment/SOURCES.md)。

`assets/equipment/icon-assignments.json` 固定记录每个条目对应的原图；`icon-manifest.json` 保存衍生文件的来源 ID、文件及解码像素 SHA-256、尺寸与抠图说明。166 个图标键、原图 ID、文件内容及解码像素均唯一。准备脚本会拒绝重复图片与无透明背景的输出，浏览器验收会逐张解码确认可见主体和透明区域。

## 查询与数值

支持中文、英文与特效描述搜索，可组合分类、版本、武器等级、魔法武器、兵种特效、攻击／辅助魔法及英雄遗产筛选，可按威力、重量与等级排序。分类旁数字为基础版记录数。

- 武器及辅助装备数值沿用 2026-11-10 核对的 [Triangle Attack 武器资料](https://www.fe3h.com/weapons) 与 [装备资料](https://www.fe3h.com/equipment)，每条详情保留具体来源链接。
- 魔法资料来自 Serenes Forest，保留 14 黑魔法、8 暗魔法、14 白魔法的数值和效果。图鉴收录不代表角色已学会，爽世初始只学会火焰与圣疗，后续按等级解锁。
- 药品效果与次数核对自 [Serenes Forest 消耗品](https://serenesforest.net/three-houses/weapons-and-items/consumables/)，详情展示使用次数与本作价格。药品及转职证使用方式见 [商店与转职](SHOP-RECLASS-MAGIC.md)。
- 武器记录保存等级、耐久、威力、命中、必杀、射程、重量、伤害类型与特效；辅助装备没有武器等级和耐久时使用 `null`。
- 强化版保存强化后的最终值，详情显示相对基础版的变化。例如铁剑＋命中为 100，雷剑＋射程为 1–3；训练用拳套的零威力仍保留为 0。
- 魔法详情显示每章次数、数值、效果及动态射程说明；法杖属于辅助装备，魔法属于角色习得能力、不占背包。

130 条器物记录同步导出为 [装备数值 CSV](equipment-reference.csv)，使用 UTF-8 BOM。统一查询接口为 `src/codex-data.js`，装备与魔法规则仍分别位于各自数据模块；可配置背包和实战使用范围由 `src/inventory.js` 控制。详见 [背包与已学魔法](INVENTORY-MAGIC.md)。

## 离线与验收

`index.html` 读取本地资源；`standalone.html` 内嵌数据、代码、样式及当前 166 张独立图标，可单文件离线运行。角色背包及已学魔法界面使用同一套图标映射。外部资料页仅在主动点击来源链接时打开。

全部 15 个测试文件通过。`tools/verify-codex-browser.js` 在真实 Edge 浏览器中分别测试普通版与单文件版，覆盖 166 张图片解码及透明背景、图片去重、武器／魔法分类、搜索空结果、强化版切换、44 种职业、舞者条件与 DLC 分级。单文件版测试期间屏蔽 HTML 以外的全部网络请求，仍能完成上述验收。
