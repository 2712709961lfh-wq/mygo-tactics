# v5.19.0 界面调整

参考用户提供的《风花雪月》行动菜单、状态页截图，保留项目现有纸张、皮革和本地角色素材。

## 连续行动

1. 选择我方角色，点击蓝色范围内的落点；点击自身或「原地行动」可直接进入行动菜单。
2. 行动菜单位于角色旁。「攻击」打开同一位置的武器列表，显示实际可用武器、魔法的威力、命中、射程与剩余耐久／次数。
3. 选定武器后，如有可攻击敌人，直接进入地图目标选择；没有目标时返回行动菜单，可切换武器或撤回移动。单纯切换「武器／魔法」不消耗行动。
4. 职业攻击战技选定后进入目标选择；辅助魔法、辅助战技、药品在就地面板内选择，沿用原有实际消耗、行动结束与结算规则。辅助魔法最后一步保留施放确认。
5. Esc／右键从子列表逐级返回；目标选择返回行动，行动再返回移动。撤回移动保留原有位置校验和行动状态规则。

菜单使用角色地图投影坐标，结合 Canvas 的显示尺寸与视口滚动计算锚点。它与地图位于同一个横屏画布内，跟随统一旋转、缩放；左右侧位置考虑战场边界与可攻击敌人的遮挡，列表过长时内部滚动。

## 角色资料

- 左栏：姓名、性别、头像、职业、等级、行动状态、HP、EXP、八项能力、属性总和及命中／必杀／攻速／回避／必杀回避。
- 中栏：当前武器、辅助装备、武器参数、五格真实背包、已学可用战技。
- 右栏：通用与个人天赋、五栏已装备专精技能、当前职业经验与专精奖励。
- 特技、技能与战技使用原生可聚焦的折叠条目，默认收起，点击或键盘展开效果；同一时间只展开一项。未觉醒／未解锁项降低视觉强调并显示解锁等级或奖励状态。
- 每栏独立滚动；基础信息无需滚动即可看全。成长率、背包配置、已学魔法、职业目录、职业专精保留独立页签及原有管理功能。
