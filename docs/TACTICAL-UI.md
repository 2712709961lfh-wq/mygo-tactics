# 战场操作与角色资料

参考用户提供的《风花雪月》行动菜单、状态页截图，保留项目现有纸张、皮革和本地角色素材。

## 连续行动

1. 选择我方角色后，地图显示蓝色移动范围，指向蓝格预览路线，点击确认落点。点击角色自身或右侧情报栏的「原地行动」可直接进入行动菜单。
2. 确认落点后，行动菜单出现在角色旁。若有可用武器或攻击魔法能攻击到敌人，则显示「攻击」。武器列表只列出够得到目标的选项，选定后直接进入地图目标选择。
3. 「装备」可切换反击所用的武器或攻击魔法，不消耗行动。主动攻击结算后，装备本次攻击用的武器或魔法。预览后取消会保留原装备，耐久或次数耗尽时自动切换到可用装备。
4. 能施放治疗魔法的角色显示独立「治疗」，当前职业为舞者时显示「跳舞」。暂时没有目标或可用次数时对应指令置灰。其他辅助法术归入「辅助魔法」，药品与职业战技仍单独选择。
5. Esc／右键从子列表逐级返回；目标选择返回行动，行动再返回移动。撤回移动保留原有位置校验和行动状态规则。

移动、选攻击目标和选传送落点时，按钮放在右侧情报栏，地图缩放工具位于战场上方，临时提示显示在下方状态栏。角色旁行动菜单跟随地图视口，位置考虑战场边界和可攻击敌人，列表过长时内部滚动。移动选格参考[任天堂《火焰纹章 风花雪月》官方战斗页](https://www.nintendo.co.jp/switch/anvya/pc/system/battle.html)中的实机画面。

## 角色资料

- 左栏：姓名、性别、头像、职业、等级、行动状态、HP、EXP、八项能力、属性总和及命中／必杀／攻速／回避／必杀回避。
- 中栏：当前武器、辅助装备、武器参数、五格真实背包、已学可用战技。
- 右栏：通用与个人天赋、五栏已装备专精技能、当前职业经验与专精奖励。
- 特技、技能与战技使用原生可聚焦的折叠条目，默认收起，点击或键盘展开效果；同一时间只展开一项。未觉醒／未解锁项降低视觉强调并显示解锁等级或奖励状态。
- 每栏独立滚动；基础信息无需滚动即可看全。成长率、背包配置、已学魔法、职业目录、职业专精保留独立页签及原有管理功能。
