# v5.3 背包与等级学法术

打开 `index.html` 或重新生成的 `standalone.html`。标题页 → 同行之人 → 背包配置 / 已学魔法。

器物图鉴也可统一查询全部 36 种魔法：选择「魔法」或「黑魔法 / 暗魔法 / 白魔法」分类，支持中英文名称、效果搜索，等级、攻击 / 辅助魔法筛选与数值排序。详情显示威力、命中、必杀、重量、每章次数、射程及效果，并说明按魔力计算的射程。魔法没有强化版；选择强化版后切入魔法分类会自动回到普通版。图鉴收录不授予角色魔法，爽世初始学会火焰与圣疗，后续按等级解锁；转入魔法职业的同伴使用同一学习曲线。

## 使用方式

- 每名角色 5 格物理背包；一件武器和一件辅助装备可同时生效，两者都占格。运输队是有限共享库存，存取保留每件物品的剩余耐久。
- 初始职业保留角色既有武器专长，转职后按职业擅长的剑 / 枪 / 斧 / 弓 / 格斗类别装备。可以携带其他类别，但不能装备。武器损坏后切换为背包中的可用武器；没有可用攻击手段时不可攻击、反击。
- 当前背包支持图鉴内武器、辅助装备、五种药品和七种转职证。五类基础武器及特殊武器分章进入商店货架。辅助装备中，表中对应的守备、魔防、命中、暴击、速度、回避、移动、魔攻、治疗加成均已接入。
- 行旅商店支持购买与出售，商品随四章进度开放；新游戏运输队仅25瓶伤药与铁剑、铁枪、铁斧、铁弓、铁拳套各一件。角色五格背包与运输队存取保留药品次数和武器耐久。详见 [商店、药品与转职规则](SHOP-RECLASS-MAGIC.md)。
- 我方阶段、角色尚未行动、没有正在移动或攻击的单位时可以整理背包；胜利后也可整理，带入第二章。
- 背包配置不会自动覆盖已有存档；点击存档可保存配置。下一章继承背包、装备、耐久和运输队。

## 魔法与战斗

- 导入《风花雪月》通常可学习的 36 种魔法：14 黑魔法、8 暗魔法、14 白魔法。每个角色、每个魔法分别记录次数，不占背包，也不是可交易魔法书。
- 每场战斗内不随回合刷新；进入下一章时补满魔法次数，物理武器耐久继续保留。
- 行动面板 → 武器 / 魔法，可切换当前攻击，或者选择辅助魔法。当前攻击用于防守反击；治疗不会把反击攻击手段换成治疗。
- 攻击、反击、追击均逐击消耗 1 次或 1 耐久，包括未命中；最后一次资源不足以支撑追击。预告和动画预演不会扣除真实资源，确认交战结算后才统一应用。
- 进攻魔法按魔力对魔防结算；范围、威力、命中、暴击和重量来自资料表。月神无视魔防且不追击；雷暴、陨石不追击；吸取回复实际伤害的一半；圣风、黑暗尖刺、天使对相应标签威力 ×3。
- 沼泽 / 虫群 / 魔女在命中后施加守备 / 速度 / 移动 −5，持续至目标下次行动阶段结束。沉默封锁施法与魔法反击，到目标下次行动阶段结束解除。
- 治疗＝魔法威力＋⌊魔力/3⌋＋治疗杖加成；远程圣疗射程为魔力/2；全体圣疗与复原按魔力/4范围影响友军。
- 魔防支援增加 7 魔防，受益者的每个己方阶段开始衰减 1；救援拉回合法相邻空格；传送先选相邻友军，再在地图选择魔力/4范围内的空格，最后确认。
- 照明（Torch）保留在图鉴，但当前关卡使用自身的视野与探索机制，未接入照明法术，因此不开放无效的照明行动。
- 敌方专用的 Bohr Χ / Quake Σ 不属于本次 36 种可学魔法。兵种的魔法次数减半 / 加倍、熟练度成长不在本次范围。
- 武器命中使用图鉴绝对命中值，避免与旧模板的固定命中重复相加。物理加技巧，魔法加⌊(技巧＋幸运)/2⌋。原型现有地形回避、武器三角和暴击伤害倍率沿用之前版本；本次未宣称完整复刻原作所有战斗规则。
